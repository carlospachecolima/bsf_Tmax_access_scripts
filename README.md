# Automated Tmax Mapping Scripts for the São Francisco Region (BSF)

This repository contains Python scripts developed for QGIS to automate the generation of Tmax (maximum temperature) maps under future climate scenarios. The scripts are designed for use with CMIP6 projections and support impact assessments in the Baixo São Francisco (BSF) region.

## Description

These tools allow users to:

- Style Tmax raster layers based on classification thresholds
- Generate monthly maps for different Shared Socioeconomic Pathways (SSP126, SSP245, SSP370, SSP585)
- Automate layout creation using predefined templates (.qpt)
- Export final maps as high-resolution PNGs
- Facilitate climate risk mapping and scenario-based agricultural planning

## Requirements

- QGIS 3.28 or higher
- Python 3.9+
- CMIP6 Tmax raster files (e.g., from WorldClim v2.1 or downscaled models)
